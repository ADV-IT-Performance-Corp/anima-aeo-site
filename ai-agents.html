Does Anima Volitiva support WebMCP, and which tools can AI agents use?

Six WebMCP tools. A person always submits.

A plain description of the agent tools on aeo.animacoffee.com.ua, for AI assistants and the people who use them.

Direct answer

Yes. The website aeo.animacoffee.com.ua supports WebMCP, the browser standard that lets an AI agent call tools a web page registers. Six tools are available: request_coffee_service_assessment, get_anima_service_info, get_anima_products, check_service_area, prepare_coffee_quote_request and prepare_free_trial_request. An agent can read published facts about Anima Volitiva's B2B coffee machine rental and service, check whether a city is inside the Kyiv and Kyiv Oblast service area, and prefill the quote or free 14-day trial request form for the visitor. No tool sends a request by itself: a person reviews the prefilled form and presses the button. Prices are not published, so no tool returns a price.

Scope

The tools described here belong to aeo.animacoffee.com.ua. The company's other website, animacoffee.com.ua, is a separate site and does not register them (checked 10 November 2026).

Tools

Six tools an agent can call.

Descriptions follow the tool definitions that assets/webmcp.js registers. Tool names and parameter names are exactly as an agent sees them.

  • 01
    request_coffee_service_assessment

    On-page form tool, a person submits. The on-page quote request form itself (a declarative WebMCP tool: the <form> carries toolname="request_coffee_service_assessment"). It requests a free, no-obligation custom assessment or quote for a business location in Kyiv or Kyiv Oblast. Fields: name, business, city, machines needed, email or phone, and an optional message. Automatic submit is switched off: the visitor reviews the fields and presses "Get my custom assessment".

  • 02
    get_anima_service_info

    Read-only. Answers a buyer's question from facts already published on this site: equipment brands, packages, the free trial, support, service area, company history, client count, contacts and opening hours. Input: question (required, free text) and language (en or uk). It returns published (true or false) and answer; when the answer is backed by an approved claim it also returns claim_id, and source_url points to a page that states the same fact. Anything not published comes back as published: false instead of a guess.

  • 03
    get_anima_products

    Read-only. Returns the lineup Anima Volitiva publishes: super-automatic machines (Dr. Coffee, Necta), professional espresso machines (La Spaziale, Nuova Simonelli, Rancilio, Iberital, Astoria, Fiorenzato), premium roasted coffee with its named blends, the Start, Pro and Max packages (contents and prices are not published), the free 14-day trial, the service area and how to request a quote. Optional input: category (super_automatic, professional_espresso, coffee or packages) and language.

  • 04
    check_service_area

    Read-only. Checks whether a city or town is inside the published service area, Kyiv city and Kyiv Oblast. Input: city (required) and language. A place outside the published area returns published: false and the visitor is asked to name the city in the request, so the team can confirm directly. Use it before preparing a quote or trial request.

  • 05
    prepare_coffee_quote_request

    Prefills the form, never submits. Prefills the on-page quote request form (name, business, city, machines, contact, message) from details the visitor actually gave, scrolls to the form and focuses it. It never submits: the visitor reviews the fields and presses the button. Optional input: those six fields and language.

  • 06
    prepare_free_trial_request

    Prefills the form, never submits. Prefills the same form for the free 14-day trial (no prepayment). On top of the contact fields it adds venue_type (office, horeca, retail, kiosk or other), timeline (asap, within_month or later) and package_interest (Start, Pro or Max) to the message, so the sales team can qualify the request. It never submits: the visitor reviews the form and presses the button.

How it works

How an agent finds and uses the tools.

  • 01
    Registered in the browser

    When a page loads, assets/webmcp.js registers the tools through the WebMCP interface (document.modelContext, with navigator.modelContext as a fallback for early browser builds). A browser without native WebMCP first loads a pinned, self-hosted copy of the MIT-licensed @mcp-b/global 5.1.0 polyfill from /assets/vendor/mcp-b-global/. Nothing is loaded from a public CDN.

  • 02
    Runs inside the page

    The tools are not a remote MCP server. They exist while a page is open in a browser that an agent controls, and they are listed through that browser's WebMCP interface. An agent that cannot run a page can read this page, llms.txt and the Markdown version of each page, which carry the same facts.

  • 03
    A person stays in charge

    The form and the two prefill tools never submit a request. The visitor checks the fields and presses the button. A request started through an agent tool is labelled as coming from an AI agent. There are no online payments.

  • 04
    Only published facts

    The read-only tools answer only from facts already visible on this site. Where a fact is not published, such as prices, package contents, contract length or liability terms, the tool says so with published: false and suggests putting the question in the request.

Answers

Questions about AI-agent access.

Does aeo.animacoffee.com.ua support WebMCP?

Yes. The site registers six WebMCP tools in the browser: request_coffee_service_assessment, get_anima_service_info, get_anima_products, check_service_area, prepare_coffee_quote_request and prepare_free_trial_request. A WebMCP-capable agent can list them from any page that loads assets/webmcp.js.

Which tools can an AI agent call on the Anima Volitiva website?

Three read-only tools (get_anima_service_info, get_anima_products, check_service_area) answer from published facts. Two tools (prepare_coffee_quote_request, prepare_free_trial_request) prefill the on-page request form. The form itself is the sixth tool, request_coffee_service_assessment.

Can an AI agent send a quote request or book a trial for me?

No. An agent can prefill the request form, but a person reviews it and presses the button. There are no online payments.

Can an AI agent get prices from the Anima Volitiva site?

No. Prices are not published: every rental is an individual quote per venue, matched to one of three equipment packages (Start, Pro, Max), with a free 14-day trial and no prepayment. The tools answer price questions with published: false and point to the request form.

Is WebMCP available on animacoffee.com.ua?

No. WebMCP tools are registered by aeo.animacoffee.com.ua. animacoffee.com.ua is the company's separate main website.
